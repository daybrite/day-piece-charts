# day-piece-charts

Build reactive charts from marks, scales, and data.

[Day](https://daybrite.dev/docs/) is a Rust framework for building apps with native desktop and
mobile controls, plus HTML controls on the web.

Compose line, area, bar, sector, and point marks on Day’s canvas. Add selection, legends,
animation, and image or PDF export. The gallery crate supplies reusable example pages.

## Use

Add `day-piece-charts = "0.*"` to your app’s `[dependencies]`.
Build with the Day CLI to select the matching toolkit integration.
