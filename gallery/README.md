# day-piece-charts-gallery

Embed the chart examples in another Day app.

[Day](https://daybrite.dev/docs/) is a Rust framework for building apps with native desktop and
mobile controls, plus HTML controls on the web.

The library supplies reusable pages, localized labels, and chart export menus. Use it for
interactive examples or as a starting point for your own chart interface.

## Use

Add `day-piece-charts-gallery = "0.*"` to your app’s `[dependencies]`.
Build with the Day CLI to select the matching toolkit integration.
